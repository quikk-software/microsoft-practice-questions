# Introduction

Organizations today need to build custom tools, automate processes, and gain data insights faster. Traditional software development can be slow, expensive, and dependent on specialized technical talent. Microsoft Power Platform addresses this challenge.

This module introduces you to Power Platform and the products that compose it. Whether you're a business analyst, operations manager, or someone who has never written a line of code, you discover how Power Platform helps people across an organization build solutions that matter—without waiting months for IT to deliver them.

You explore each component of the platform, learn how they work together, and understand how organizations are using them to solve real business problems every day.

## Learning objectives

In this module, you learn how to:

*   Describe the value of Power Apps to build applications.
*   Describe the value of Power Automate to automate processes.
*   Describe the value of Power Pages to build websites.
*   Describe the value of Dataverse to organize business data.
*   Describe the value of Copilot Studio to create agents.
*   Describe the value of copilots and generative AI features in Power Platform.
*   Describe the value of connectors to integrate services and data for apps and flows.
*   Describe the value of Plan Designer.
