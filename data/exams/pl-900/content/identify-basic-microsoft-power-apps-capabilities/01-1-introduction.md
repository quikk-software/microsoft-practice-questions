# Introduction

Microsoft Power Apps is a low-code application development platform that lets anyone in an organization—from business users with no coding background to professional developers building enterprise-grade solutions—create custom apps that solve real business problems. Power Apps offers multiple app development approaches, each suited to a different combination of user skill, scenario complexity, and design flexibility.

Imagine you work at Contoso, a global manufacturing company. Different teams across the organization have different application needs. The field service team needs a mobile app to submit inspection reports from the factory floor. The operations management team needs a full enterprise dashboard to track orders, customer cases, and team performance with complex business rules. The IT development team is building a customer-facing web portal that requires complete control over the design and must integrate with a proprietary legacy system. Power Apps provides the right tool for each of these scenarios—and Copilot helps every maker get started faster by turning plain-language descriptions into working apps and data models. For teams that need to build complete multi-component solutions—combining apps, flows, and agents—Power Apps also offers Plans, a copilot-first tool that generates a full Power Platform solution from a natural language description and a few visuals. This module focuses on the three app types: canvas apps, model-driven apps, and code apps.

## Learning objectives

In this module, you learn how to:

*   Describe the use cases and capabilities of canvas apps.
*   Describe the use cases and capabilities of model-driven apps.
*   Describe the use cases and capabilities of code apps.
*   Create a canvas app through conversations with Copilot.
*   Create a model-driven app through conversations with Copilot.
