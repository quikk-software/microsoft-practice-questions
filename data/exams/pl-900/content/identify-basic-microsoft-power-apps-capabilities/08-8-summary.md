# Summary

In this module, you explored the three app development approaches available in Microsoft Power Apps and how Copilot accelerates the creation of each app type through natural language conversations.

You learned that canvas apps are Power Apps' most flexible app type, giving makers complete control over the user interface and the ability to connect to 200+ data sources. Canvas apps are ideal for task-specific, mobile-first scenarios such as field inspections, service requests, and data capture. Copilot helps makers build canvas apps by generating Dataverse tables and app screens from a natural language description, and Microsoft 365 Copilot gives app users the ability to ask questions about their data directly within the deployed app.

You explored model-driven apps, which take a data-first approach by building on a Dataverse data model and generating a responsive user interface automatically. Model-driven apps excel at complex data management scenarios—case management, sales pipelines, employee management, and operational dashboards—with built-in business process flows, role-based security, and activity timelines. Copilot supports both the creation of the data model and the ongoing experience of app users through natural language queries.

You also learned about code apps, Power Apps' pro-developer option for building fully custom web applications in frameworks such as React or Vue using Visual Studio Code. Code apps bring Power Platform connector access and governance to custom development, and the extensibility spectrum helps organizations match the right app type to every scenario.

Finally, you walked through the complete Copilot-driven creation experience for both a canvas app (the Contoso Equipment Request app) and a model-driven app (the Contoso Service Management app), from describing the data model in natural language through refining, customizing, and publishing each app.

## Skills you've gained

After completing this module, you can:

*   Describe canvas apps, their key capabilities, and the scenarios they're best suited for.
*   Describe model-driven apps, their data-first design approach, and the enterprise scenarios where they excel.
*   Describe code apps and explain when professional developers should choose them over low-code alternatives.
*   Select the right app type for a given business scenario using the canvas vs. model-driven comparison.
*   Use Copilot in Power Apps to create a canvas app from a natural language description and refine it in Power Apps Studio.
*   Use Copilot in Power Apps to generate a model-driven app, customize it in the app designer, and enable Microsoft 365 Copilot for app users.
