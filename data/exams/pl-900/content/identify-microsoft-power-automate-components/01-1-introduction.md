# Introduction

Microsoft Power Automate is a cloud-based process automation platform that lets anyone in an organization—from business users to professional developers—streamline repetitive tasks, automate workflows, and connect applications and services without deep programming expertise. Power Automate spans from simple personal productivity automations to enterprise-grade robotic process automation.

Imagine you work at Contoso, a mid-sized manufacturing and professional services company. Teams across the organization spend significant time on repetitive manual tasks: forwarding emails to team members, copying data from one system to another, routing documents for approval, entering data from forms into databases, and running the same reports every Monday morning. Power Automate can eliminate each of these manual steps—freeing employees to focus on higher-value work and reducing the errors that come with manual processes.

## Learning objectives

In this module, you learn how to:

*   Describe use cases for cloud flows and desktop flows.
*   Describe Power Automate use cases for approvals, Microsoft Teams, Outlook, SharePoint, Forms, and document automation.
*   Describe triggers for cloud flows.
*   Describe actions for cloud flows.
*   Create and modify cloud flows through conversations with Copilot.
*   Create and modify desktop flows with Copilot.
*   Describe how to build cloud flows using the designer.
