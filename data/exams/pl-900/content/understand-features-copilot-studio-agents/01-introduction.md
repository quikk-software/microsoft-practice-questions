# Introduction

Microsoft Copilot Studio is a software-as-a-service (SaaS) agent platform that enables organizations to build, deploy, and manage intelligent agents without requiring deep programming expertise. Agents built in Copilot Studio can answer questions from knowledge sources, take action through tools and connectors, automate multi-step business processes, and integrate with hundreds of external systems—all through a guided, low-code authoring experience.

Imagine you work at Contoso Professional Services, a global professional services company. Your team handles thousands of employee inquiries each week about HR policies, IT support, and benefits enrollment. Leadership wants to reduce the burden on your helpdesk while improving the experience for employees who need fast, accurate answers at any time of day. Microsoft Copilot Studio gives your team the tools to build intelligent agents that serve these use cases—grounded in your company's own data, governed by your security policies, and measurable through built-in analytics.

In this module, you'll learn how to:

*   Describe use cases for Copilot Studio agents
*   Describe how Copilot Studio uses your data
*   Describe the Copilot Studio data flow
*   Describe how knowledge and tools are used in agents
*   Describe how MCP servers are used in agents
*   Describe how to monitor Copilot Studio agent usage and adoption
*   Describe agent flows
*   Describe agent evaluations
*   Describe the Copilot Studio agent development process
*   Build an agent in Copilot Studio
