# Introduction

In today's tech environment, a global consulting firm faces a challenge: managing data that ranges from public to highly confidential. The shift to remote work makes having a strong system to classify, protect, and monitor data within Microsoft 365 more important than ever. Microsoft Purview Information Protection offers a solution with sensitivity labels. This module shows how the firm uses these labels to boost data security, ensure compliance, and enhance collaboration across its global workforce.

## Learning Objectives

In this module you:

*   Understand the fundamentals of Microsoft Purview sensitivity labels and their integration in Microsoft 365.
*   Create and publish sensitivity labels to classify and protect different types of data.
*   Configure encryption settings with sensitivity labels to enhance data security.
*   Implement auto-labeling policies for efficient data classification and protection.
*   Use the Microsoft Purview data classification dashboard to monitor and manage the use of sensitivity labels.

## Prerequisites

*   Basic familiarity with Microsoft 365 and its various applications.
*   An understanding of data protection concepts and the importance of data security in an organizational context.
