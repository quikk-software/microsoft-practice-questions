# Module assessment

## Check your knowledge

1.

Your organization uses SharePoint Server 2019 to store HR documents. You want to automatically apply a sensitivity label to files containing employee Social Security numbers. What must be in place for the scanner to apply the label?

Configure SharePoint search service with custom IFilters.

Create a sensitivity label with matching conditions and enable enforcement in the scan job.

Enable document versioning and metadata tagging in SharePoint.

2.

You've enabled data loss prevention (DLP) rules for a shared finance folder. A team member asks why access to a file was suddenly restricted. What likely triggered this action?

The file matched a DLP policy condition and triggered a restriction action.

The file was added to a retention policy with a delete action.

The scanner ran in discovery mode and flagged the file.

3.

You're reviewing scan results in the Reports folder. What would you find in the '.csv' report that isn't included in the '.txt' summary?

The total number of scanned files.

Each file's sensitivity label and DLP actions taken.

Scan duration and scanner service logs.

4.

You're configuring DLP for a new on-premises document library. What must be enabled in the scan job for DLP enforcement to work?

Enforce sensitivity labeling policy.

Enable DLP rules.

Relabel all previously labeled content.

5.

You updated your DLP policy to include new file types and ran a full rescan. Where can you verify which files triggered DLP matches?

In Activity explorer or the scanner's '.csv' report.

In Microsoft Entra audit logs, under identity protection events.

In the classification overview under sensitivity label analytics.
