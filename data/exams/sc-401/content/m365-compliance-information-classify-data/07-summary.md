# Summary

Classifying data is a critical step in protecting sensitive information and ensuring compliance with regulatory requirements. Without a structured classification approach, organizations risk accidental data exposure, security breaches, and governance failures.

This module explored how Microsoft Purview helps organizations classify and protect both structured and unstructured data at scale. By using sensitive information types (SITs) and trainable classifiers, organizations can automate classification, apply security policies, and enforce data governance across Microsoft 365 services.

In this module, you learned to:

*   Explain the importance of data classification for protection and governance.
*   Describe how sensitive information types (SITs) classify structured data.
*   Explain how trainable classifiers identify unstructured data.
*   Create a custom trainable classifier to detect organization-specific content.
