# Module assessment

## Check your knowledge

1.

Where do you go in Microsoft Purview Insider Risk Management to view all alerts generated by policies?

Cases dashboard

Activity explorer

Alerts dashboard

2.

How does the scatter plot in the User activity tab help investigators?

It maps user behavior to Microsoft Entra ID roles.

It visualizes risk-scored events over time to identify sequences and patterns.

It provides direct access to Copilot summaries for each activity.

3.

What is a recommended next step if an alert involves multiple serious activities across different services?

Dismiss the alert to avoid duplication.

Create a case to manage follow-up actions and collaboration.

Delete the alert to reduce dashboard clutter.

4.

What role do cases play in insider risk investigations?

They track licensing for each alert.

They allow grouping and managing alert investigations for a specific user.

They store Power Automate logs for compliance tracking.

5.

Which role is required to use Advanced hunting for insider risk events?

Microsoft 365 Compliance Administrator

Insider Risk Management Analyst or Investigator
