# Introduction to environment roles

Now that we've reviewed the security concepts, this module will dive deeper into security roles and teams. We'll explore the standard security roles provided out of the box by Dataverse, demonstrate how to create custom security roles tailored to your organization's needs, and demonstrate how to add users to environments and security roles.
