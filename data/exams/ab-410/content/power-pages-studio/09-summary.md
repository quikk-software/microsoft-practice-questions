# Summary

Power Pages design studio is a straightforward, no-code, low-code environment that you use to build and configure a powerful data-driven business site.

This module covered the following topics:

*   The structure and features of the Power Pages design studio.
*   How to add pages and organize them in the hierarchy of the site.
*   How to add various components to site pages.
*   How to view and edit page source code.
*   Different methods to modify the site appearance.
*   How to configure security using the Security workspace, including web roles, page and table permissions, and identity providers.
*   How to add Copilot and AI features throughout the design studio, including AI-generated pages, text, forms, and themes.
*   How to add an AI-powered agent to provide conversational support to site visitors.
