# Introduction to Power Pages design studio

Power Pages provides a unified, intuitive experience for makers to create, customize, and manage modern data-driven business websites. Just sign in to [https://make.powerpages.microsoft.com/](https://make.powerpages.microsoft.com/) to get started.

![Screenshot of Power Pages Home.](media/1-power-pages-home.png)

**Power Pages Home** provides a single view of all your websites in an environment and allows you to create more sites by using the available templates.

**Template hub** accelerates creation of new sites by using feature-rich templates that target specific business scenarios. To solve unique business needs, start with one of the generic design templates that include page structures, navigation, and commonly used pages.

**Learn hub** helps makers, administrators, and developers learn how to design, build, administer, and extend sites through documentation, guided tutorials, and videos.

**Solutions** is where you can access the different solutions that are deployed to the current environment and create new ones.

**Power Platform** provides easy access to the different maker portals available, such as the Power Apps maker portal.

## Power Pages design studio

To get started with Power Pages design studio, sign in to [Power Pages Home](https://make.powerpages.microsoft.com/), select a site, and then select **Edit**. Select **Create a site** to provision a new site if necessary.

The design studio is organized into workspaces that help makers focus on specific tasks.

![Screenshot of Power Pages design studio.](media/1-power-pages-screenshot.png)

*   Design and build web pages in the **Pages workspace**. Organize site navigation and add content in a low-code environment.
    
*   Create a modern look and feel. Apply corporate branding and manage global site styles in the **Styling workspace**.
    
*   Model, visualize, and manage business data in the **Data workspace**.
    
*   Configure site settings, prepare for go-live, manage progressive web app (PWA) settings, and access the admin center in the **Set up workspace**.
    
*   Monitor, protect, and manage site security in the **Security workspace** — configure web roles, page and table permissions, Web Application Firewall, identity providers, and site visibility.
    

For advanced configurations that aren't available in the Power Pages design studio, the [Portal Management app](/en-us/power-pages/configure/portal-management-app) is accessible by selecting the **ellipsis icon** (**...**) at the bottom of the left-hand workspace navigation.

![Screenshot of Portal Management access from Power Pages design studio.](media/1-3-portal-app-access.png)

## Ask Copilot questions

While working in the design studio, you can use the Copilot sidecar to ask questions about building your Power Pages site. This is a quick way to get guidance without leaving the studio. This feature is generally available in all regions except DoD.

To ask Copilot a question:

1.  Go to the **Pages workspace**.
    
2.  In the Copilot sidecar, select **Ask**.
    
    If the Copilot pane isn't visible, select the Copilot button in the command bar. If the **Ask** option doesn't appear, your administrator might need to allow Bing search.
    
3.  Choose from the starter prompts displayed, or type your own question in the text box.
    
4.  Press Enter or select the send icon to submit your question.
    

Note

The Ask feature requires Bing search to be enabled. You're prompted to enable it the first time you use the feature, or you can select the gear icon in the Copilot sidecar to turn it on.

## Copilot governance

Administrators can control which generative AI features are available to site users across the tenant. This includes features like site search with generative AI, AI-powered list summaries, and AI form fill assistance. Makers can enable these features on their sites, but admin governance settings can override those configurations.

For more information, see [Control use of Generative AI features for users](/en-us/power-pages/admin/copilot-governance).
