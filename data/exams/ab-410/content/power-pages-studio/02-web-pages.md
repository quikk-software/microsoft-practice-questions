# Work with pages

You can quickly add and organize new pages in the **Pages** workspace of Power Pages design studio.

## Create a page

In the Power Pages design studio, select **Pages workspace**, and then select **\+ Page**.

The primary option is to create a page with Copilot. Describe the page you want to create in natural language, and Copilot generates a page layout and content for you. This feature is generally available in all regions except DoD.

To use a standard or custom layout instead, select **Other ways to add a page**. Standard layout choices depend on the site template you use. Custom layouts are the page templates that makers and pro developers add to the site.

![Screenshot of adding a web page from the Pages workspace in Power Pages design studio.](media/2-power-pages-add-page.png)

After you enter a page name and select a layout, the page appears on the canvas. You can start adding and editing components to the page.

## Configure site structure

You can configure where and how the page appears in the site navigation. Select the ellipsis (**...**) next to the page you want to move. Then, choose one of the available actions.

Note

The selection of available actions depends on the page position in the navigation.

![Screenshot of Managing page navigation after saving the page.](media/2-power-pages-navigation.png)

You can move the page up and down, make it a subpage, or hide it from the main navigation by moving it to the **Other pages** group (the page is still accessible via a URL). You can also duplicate the entire page or delete it. You can change the page hierarchy in the **Main navigation** section by dragging and dropping the page name. For the full list and detailed description of available actions, see [Create site structure](/en-us/power-pages/getting-started/structure-site).

## Preview a page

You can preview the page by selecting **Preview** from the command bar.

![Screenshot of Page preview command in Power Pages design studio.](media/2-power-pages-preview.png)

Select **Desktop** to preview your page in a browser, or scan the QR code to view the page on a mobile device.

Note

Using the preview command resets the site cache. The system retrieves a fresh copy of the site configuration and the relevant business data. This change might briefly affect the page performance.
