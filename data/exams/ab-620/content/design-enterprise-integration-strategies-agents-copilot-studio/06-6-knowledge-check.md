# Module assessment

1.

A maker configures a Copilot Studio agent that answers employee questions using indexed articles from the company's internal IT knowledge base. Which integration category does this scenario represent?

Tools, because the agent is retrieving data from an external system

Knowledge sources, because the agent grounds its responses using indexed enterprise content

Agents, because the agent delegates the question to a specialized knowledge agent

2.

An agent needs to provide answers about current inventory levels from a warehouse system. Company policy prohibits copying data to Microsoft systems, and the data changes frequently. Which knowledge source approach best fits this requirement?

A Copilot connector, because it enables semantic search over enterprise content

Azure AI Search, because it supports custom relevance tuning over enterprise data

A Power Platform connector as real-time knowledge, because it queries the live system at runtime without replicating data

3.

A Copilot Studio agent needs to file a new support ticket, send a Teams notification to the requester, and assign the ticket to a routing queue — all as a single coordinated sequence triggered by one user request. Which action integration pattern best addresses this requirement?

A prebuilt Power Platform connector tool, because connectors support multi-step operations

A REST API tool, because REST APIs can chain multiple calls in a single request

An agent flow, because it executes a deterministic, multi-step sequence of actions across connected services

4.

A maker configures a connector tool to use maker-provided credentials so all users share a single service account. The agent fails to publish to the company's anonymous intranet portal. What is the most likely cause of the failure?

Maker-provided credentials are not supported for connector tools in Copilot Studio

Agents that use maker-provided credentials can only be published to authenticated channels

The organization's data loss prevention policy is blocking the connector on the intranet portal

5.

A team needs to connect a Copilot Studio agent to a proprietary internal API that no other agent will use. They want to minimize development effort. Which integration approach is most appropriate?

A custom connector, because it provides built-in error handling and parsing

A REST API tool, because it integrates directly using an OpenAPI specification without connector packaging overhead

An agent flow, because it provides monitoring capabilities and handles high request volumes
