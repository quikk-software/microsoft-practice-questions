# Summary

Managing a complex orchestrator becomes easier when you can distribute responsibilities across specialized child agents. In this module, you built the skills to create, configure, and manage child agents in Copilot Studio — turning a difficult-to-maintain agent into a structured, domain-aware system.

## What you learned

*   Child agents are agents managed within a parent orchestrator, each focused on a specific domain with its own instructions, tools, and knowledge. They're the right architectural choice when one team owns the entire solution and there's no need to publish any component independently.
*   You create child agents by defining clear names, descriptions, and instructions that help the orchestrator understand each agent's purpose and when to delegate to it.
*   You configure inputs and outputs to pass structured data between parent and child agents, and you control the parent's response when a child agent finishes using the after-running settings.
*   You verify routing accuracy using the test panel and manage the full child agent lifecycle — enabling, disabling, redirecting to, and deleting agents as your requirements change.
