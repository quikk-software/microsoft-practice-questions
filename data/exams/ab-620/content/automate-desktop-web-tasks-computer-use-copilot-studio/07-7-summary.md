# Summary

In this module, you explored how to extend a Copilot Studio agent to automate tasks in applications that have no API or connector, using the Contoso HR attendance scenario as a through-line.

## What you learned

*   **Computer use** lets an agent interact with web browsers and desktop applications visually — no API or changes to the target system required.
*   **Evaluating fit** means choosing computer use only when UI interaction is the only automation path, with informed expectations about success rates and security considerations.
*   **Configuration** includes defining tool identity, natural-language instructions, machine selection, credentials, and access control.
*   **Monitoring** starts with the activity map and transcript view, and extends to the Dataverse logging panel for deeper debugging and audit support.
