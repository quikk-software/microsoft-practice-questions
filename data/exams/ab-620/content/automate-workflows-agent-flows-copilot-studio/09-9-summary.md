# Summary

In this module, you built the skills to design, create, and manage agent flows in Microsoft Copilot Studio, enabling you to automate multi-step, multi-system business processes reliably, without writing code.

## What you learned

*   **Agent flows** are deterministic, event-driven automation sequences built and managed inside Copilot Studio, billed through Copilot Credits using the Copilot Studio plan, making them distinct from Power Automate cloud flows in where they're built and how they're billed.
*   **Business processes suited for agent flows** are repetitive, multi-step, predictable, and event-driven—the IT support ticket scenario demonstrates how a single flow replaces five separate manual tasks across multiple systems.
*   **Natural language and the visual designer** are two complementary ways to create an agent flow. Both paths lead to the same designer, and the Copilot pane is available throughout for further iteration.
*   **Actions and connectors** make up the working body of a flow. Standard, premium, and custom connectors connect to external services, and giving each action a descriptive name makes every downstream configuration step easier.
*   **Dynamic content, expressions, conditions, and loops** allow a flow to use data from previous steps, transform and format values, branch based on evaluated conditions, and process lists of items—enabling flows to handle real-world process variation correctly.
*   **Version history, the flow checker, testing, and monitoring tabs** are the tools that validate a flow before publishing and track its performance over time, with the Savings feature cumulating business value across all successful runs.
