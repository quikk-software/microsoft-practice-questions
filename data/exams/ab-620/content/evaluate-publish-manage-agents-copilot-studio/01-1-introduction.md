# Introduction

Before you share an agent with users, you need to know that it works as expected. Microsoft Copilot Studio helps you test an agent, track how people use it, and publish it to Microsoft Teams and Microsoft Copilot.

Priya builds a Contoso agent that answers employee questions about IT and HR policies. The agent works well on the Preview tab, but Priya needs to test more than a few sample questions. She also needs to check the agent after each update and help users when the agent can't answer a question.

In this module, you learn how to:

*   Choose between quick tests on the Preview tab and repeatable tests on the Evaluate tab.
*   Create test conversations, run an evaluation, and review the results.
*   Use the Monitor tab to find quality, connection, and access problems.
*   Publish an agent to Teams and Microsoft Copilot, and check that it works for users.
*   Describe how governance and application lifecycle management (ALM) help organizations manage agents.
*   Identify activities that use Copilot Credits and where administrators track usage.

By the end of this module, you can test, publish, and manage an agent after it is available to users.
