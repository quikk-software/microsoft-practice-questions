# Introduction

## Scenario

Imagine you build agents at Contoso, and your HR self-service agent answers employee questions about leave policies. The answers are accurate, but they arrive as walls of unformatted text that are hard to scan, easy to dismiss, and nothing like the polished, purposeful experience employees expect from a workplace tool. On top of that, when an employee wants to submit a leave request, the agent walks them through four separate question-and-answer turns, asking for dates, leave type, and reason one at a time. There's a better way.

**Microsoft Copilot Studio** gives you the tools to go far beyond plain text. Using **message node formatting**, you can structure agent responses with text markup, images, videos, and quick reply buttons. With **Adaptive Cards**, you can present information as a visually rich, scannable layout and collect structured input from users in a single interactive form, all without writing code.

Note

Microsoft Copilot Studio has introduced a new experience with updated features, capabilities, and navigation. This module is based on the **classic experience**. For more information, see [Classic vs. new agent experience](/en-us/microsoft-copilot-studio/agents-experience/classic-vs-new).

## What you'll learn

In this module, you learn to configure message formatting options, design informational Adaptive Cards that display structured data in clean layouts, configure **Ask with Adaptive Card** nodes that collect input without multi-turn questioning, use the built-in Adaptive Card designer and JSON editor, and apply channel-specific schema considerations so your cards render correctly in Microsoft Teams, the web chat surface, and beyond. The Contoso HR scenario threads through each unit to show how these capabilities come together in a real workplace context.

## Goal

By the end of this module, you'll be able to build professional, interactive agent experiences designed for real workplaces, going well beyond plain text to create responses that are clear, engaging, and easy to act on.
