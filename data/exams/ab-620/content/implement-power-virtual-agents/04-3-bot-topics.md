# Agent topics permissions

Topics are the no-code way to create discrete conversation paths that, when used together within a single agent, allow users to have a conversation with an agent that feels natural and flows appropriately.

Topics are siloed in each agent and can't be shared, even if they're part of the same environment. You can copy an existing topic, which is automatically created and saved in the same agent, and, by default, **Enabled** is set to **Off**.

[![List of topics with the ellipsis button selected next to Lesson 1 - A simple topic, and with the Make a copy option highlighted.](media/make-copy.png)](media/make-copy.png#lightbox)

When an agent is created, it includes seven **Custom** topics and nine **System** topics. The system topics are used to provide core functionality and can't be turned off.

[![Screenshot of topics showing eight system topics.](media/system-topics.png)](media/system-topics.png#lightbox)

You can export and import topics from one environment to another by using solutions and migrating the entire agent. In **Solutions**, you can add your existing agent, and it includes all its topics automatically.
