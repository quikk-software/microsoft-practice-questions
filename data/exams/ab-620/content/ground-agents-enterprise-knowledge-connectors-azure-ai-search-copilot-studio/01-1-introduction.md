# Introduction

Agents built in Microsoft Copilot Studio are only as useful as the knowledge they can access. Many organizations store valuable information well beyond Microsoft 365 — in graph-indexed enterprise systems, live transactional databases, and document vaults optimized for semantic search. Connecting an agent to the right knowledge source for each type of content is what lets it give staff accurate, up-to-date answers.

Note

Microsoft Copilot Studio has introduced a new experience with updated features, capabilities, and navigation. This module is based on the **classic experience**. For more information, see [Classic vs. new agent experience](/en-us/microsoft-copilot-studio/agents-experience/classic-vs-new).

## Scenario

Consider a retail banking maker at Woodgrove Bank who is building a **branch staff support agent**. Staff need answers from three very different sources: an IT knowledge base of procedures and escalation guides, live core banking account data, and a vault of regulatory compliance documents. Each source requires a different approach to connect it to the agent effectively.

## What you'll learn

In this module, you learn how to choose the right knowledge source for each scenario, add a Copilot connector to an agent, configure a Power Platform connector for real-time data retrieval, connect an Azure AI Search vector index, and set up the authentication settings required for publishing agents that draw on these sources.

## Goal

By the end of this module, you'll be able to connect an agent to enterprise knowledge sources (including Copilot connectors, real-time Power Platform connectors, and Azure AI Search indexes) and configure the authentication required to publish it.
